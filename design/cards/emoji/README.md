# ایموجی‌های پیش‌نمایش کارت

دو دارایی PNG برای یکسان‌بودن نمایش 🌱 و 🔥 در پیش‌نمایش تعاملی استفاده شده‌اند. renderer بازی هنوز از آن‌ها استفاده نمی‌کند.

- سازنده و انتساب: **Twemoji graphics by Twitter, Inc. and other contributors**.
- نسخه: **14.0.2**؛ فایل‌ها بدون تغییر گرافیکی استفاده شده‌اند.
- مجوز تصاویر: **Creative Commons Attribution 4.0 International (CC BY 4.0)**؛ متن کامل در [LICENSE-GRAPHICS.txt](LICENSE-GRAPHICS.txt).
- منبع [seedling.png](https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/assets/72x72/1f331.png) و [fire.png](https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/assets/72x72/1f525.png).
- منبع [مجوز نسخه](https://cdn.jsdelivr.net/gh/twitter/twemoji@14.0.2/LICENSE-GRAPHICS)، [مخزن](https://github.com/twitter/twemoji) و [خلاصهٔ مجوز](https://creativecommons.org/licenses/by/4.0/).

در صورت استفاده در نسخهٔ توزیع‌شده، این انتساب و پیوند مجوز همراه فهرست دارایی‌ها حفظ شود. مجوز این تصاویر، مجوز کل مخزن را تغییر نمی‌دهد. نام قابل خواندن برای ابزار دسترسی همراه نشان باقی بماند؛ معنای رنگ و ایموجی به‌تنهایی آزمون فهم کودک را جایگزین نمی‌کند.
