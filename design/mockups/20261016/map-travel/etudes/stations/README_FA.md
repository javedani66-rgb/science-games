# ساخت ایستگاه جدید با کیت (`etudes/station_kit.py`)

1. فایل `stations/<id>.py` بساز؛ در بالا: `sys.path.insert(0, پوشهٔ etudes)` و `from station_kit import *`. بعد از import دوباره `HERE = Path(__file__).parent` بگذار.
2. `pen = Pen('<id>', 'land')` (کرم/زیتونی) یا `'sea'` (آبی روشن/تیره). اندازهٔ سکو پیش‌فرض rx 76، ry 38، wall 16 (واحد symbol).
3. اول از همه `pad(pen, line=((x,y),(x,y)), tri=((x,y),(x,y)), dot=(x,y))` را صدا بزن: یک خط روشن، دو مثلث، یک نقطه.
4. قهرمان را مستقیم در مختصات symbol بکش (مرکز سکو = (0,0))، با `pen.shape`، `pen.fill`، `pen.ln`. هیچ `scale()` روی زیرگروه نگذار؛ برای چرخاندن از `rot()` استفاده کن.
5. ضخامت‌ها فقط از ثابت‌ها: `OUT` (دور، 7٫۶ واحد ≈ 5٫۵px نقشه)، `PART` (جزء، 5٫۸ ≈ 4٫۲px)، `INNER` (داخلی/درز، 3٫۹ ≈ 2٫۸px) (D113: هم‌قطر مرجع M09 و راه).
   خط ضخیم جزئیات ریز را می‌بلعد: به‌جای نازک‌کردن، جزء را ساده/بزرگ کن (D110)؛ پهنای مفید یک جزء رنگی ≥ ۲۰ واحد؛ نوار و میوهٔ کوچک فقط رنگ تخت (`pen.fill` / `raw`) بدون خط دور.
6. هر خط مهم را با `probe='نام'` ثبت کن تا `width_check` بسنجد.
7. بخش متحرک را داخل `with layer(pen, 'نام'):` بکش؛ id می‌شود `node_<id>_<نام>`.
8. زیر قهرمان `pen.tipshadow(x,y,r)` و `pen.foot_tip(x,y,r)` بگذار (ردپای تماس).
9. `finish(pen, '<id>', STAND, motion={'نام': dict(rotate=(x,y))} یا dict(offsets=[(dx,dy),...]), out=HERE, shots=پوشهٔ شات)`.
10. `STAND = (dx, dy)` به px نقشه از مرکز سکو: کنار قهرمان، نه روی آن.
11. خروجی: `node_<id>.svg` (symbol)، `<id>.json` (pad، stand، ring، motion) و دو شات.
12. اگر `ok` نادرست بود، کلید ناموفق را در خروجی ببین و اصلاح کن (سرریز، حاشیه ۸px، فیگور ۱۰px، قطر خط).
13. `build.py`، `template.html` و `assets/` را دست نزن؛ ادغام در نقشه کار جدا است.
14. مثال‌ها: `screw_workshop.py` (زمینی، مهره متحرک) و `wheel_dock.py` (دریایی، چرخ‌دنده متحرک).
15. اجرا: `python3 stations/<id>.py` (چند ثانیه؛ Playwright لازم است).

## چک‌لیست قواعد (D107–D115)
- قهرمان تک؛ «خانه» الزامی نیست.
- سکو هم‌ساختار چوب‌شکافی؛ بدون آجر/سنگ‌فرش؛ دریایی = همان ساختار با آبی.
- خط‌های داخلی راست و موازی؛ جزئیات کم.
- ضخامت 7.6 / 5.8 / 3.9 (حدود 5.5 / 4.2 / 2.8px نقشه)، حداقل 2.5px؛ `width_check` همه ok.
- رنگ تخت و زنده؛ سایه فقط درون سکو (`shadow_on_road_px` = 0).
- هیچ بخش از سکو بیرون نزند؛ حاشیهٔ افقی و ردپا ≥ 8px (`out_px` = 0).
- مرکز گره = مرکز بیضی سکو؛ `ring` فقط برای جبران.
- فیگور روی سکو، ≥ 10px از قهرمان و از لبهٔ رویه (`stand_*`). فیگور = سیلوئت واقعی (۵۶px + هالهٔ ۲٫۷۵px) با کف در نقطهٔ stand؛ `STAND = None` یعنی `find_stand` بهترین جا را پیدا می‌کند. جا برای فیگور یعنی قهرمان باید در ≈ ۵۷px چپِ سکو جمع شود (عرض قهرمان با خط ≲ ۵۴px، حاشیهٔ چپ ≥ ۸px).
- قاب قهرمان: `pen.xf = (مقیاس, dx, dy)` بعد از `pad()`؛ فقط هندسه مقیاس می‌شود نه ضخامت خط. در `raw` از `pen.X(...)` و برای حرکت از `pen.V(...)` / `pen.X(...)` استفاده کن.
- سایهٔ بیرونی هم‌شکل سکو (`SHADOW_DY`) در `_shadow` برای همهٔ ایستگاه‌ها یکسان است؛ `shadow_on_road_px` نوار ±۱۴px دور خط مرکز سکو را می‌سنجد.
- ردپا فقط روی راه و ≥ 15px از سکو: این را نقشه می‌سنجد، نه کیت.
- بخش متحرک لایهٔ جدا با id پایدار؛ در همهٔ وضعیت‌ها از سکو بیرون نزند و فیگور را نپوشاند (`motion_check`).
- موشن با `prefers-reduced-motion` خاموش (کار نقشه).
- `inside_check(pen, motion, min_margin=4, strict=False)` در کیت: `finish` آن را خودکار اجرا می‌کند و در json زیر `inside_pad` می‌نویسد؛ ok لازم است. strict=True (قهرمان کوتاه: غرفه، جرثقیل، چرخ‌دستی): کل قهرمان درون بیضی رویه با حاشیهٔ ≥۴px. strict=False: قهرمان بلند (برج، پیچ، دکل) می‌تواند از بالای رویه بالا برود، ولی از چپ، راست و پایین ≥۴px فاصله دارد.
