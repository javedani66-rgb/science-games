# اتود خط ضخیم روی نیما (۱۶ اکتبر)

`make.py` → `sheet.png`. ردیف‌ها: ارتفاع ۶۴، ۹۶، ۱۴۰، ۲۰۰ پیکسل (نمایش ۲ برابر برای دیدن). ستون‌ها: اصلی | فقط دورگیری بیرونی (۲–۳ پیکسل، #241a5e) | دورگیری بیرونی + ضخیم‌کردن خط‌های داخل.

یافته (فقط از روی دیدن، آزموده نشده):
- دورگیری بیرونی: کاراکتر روی سبز نقشه از زمینه جدا می‌شود و در ۶۴ و ۹۶ پیکسل خوانا می‌ماند. ساده و بدون خطر.
- ضخیم‌کردن خط‌های داخل با فیلتر: **شکست خورد**؛ مو و جزئیات صورت به لکهٔ تیره تبدیل می‌شود و عینک و دهان خراب می‌شوند. برای این کار باید شکل را برداری (SVG) از نو کشید.
