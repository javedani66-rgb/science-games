# ماکت «نقشهٔ کلی تخت» (۴ نوامبر ۱۴۰۵؛ D192)

**ماکت است؛ با کودک یا گوشی واقعی آزموده نشده (B9).** سناریو: `SCENARIO_FA.md`. ساخت: `python3 build.py` ← `template.html` + `strings.fa.json` (متن‌های `overview.*`، draft) + `review.fa.json`؛ خروجی `index.html` و `artifact.html`. ساخت منوی ورود (`../entry-page/build.py`) این صفحه را با نام `overview.html` کنار `map.html` می‌گذارد؛ پیوند منتشرشده همان پیوند منوی ورود است.

## چه دارد
- ۳۴ خانه، یکی برای هر ایستگاه، به ترتیب `ORDER` نقشهٔ بلند (آزمون برابری را می‌سنجد)؛ نماد هر خانه همان نماد نقشه؛ خانهٔ آخر فقط «؟».
- ۶ ستون، ۸ ردیف از پایین؛ هر سرزمین ردیف‌های خودش با رنگ زمین همان سرزمین در نقشهٔ بلند؛ نام هر سرزمین بالای ناحیهٔ خودش.
- رفته = تیک نقشه؛ اینجایی = حلقهٔ زرد + آدمک کودک با لباس همان سرزمین؛ جلوتر = کم‌رنگ‌تر. بدون عدد، ستاره یا امتیاز.
- لمس خانهٔ خود یا «برو» یا خانهٔ رفته: بزرگ‌شدن روی خانه ← سیاه ← `map.html#enter-<جای کودک>[-<خانهٔ زده>]`. لمس خانهٔ جلوتر: لرزش کوتاه.
- داخل نقشهٔ بلند دکمهٔ برگشت به این صفحه نیست (D192).
