# اسکیس نقشهٔ مفاهیم (پیشنهاد، نه تصمیم)

ساخته‌شده ۷ اکتبر ۲۰۲۶ بر پایهٔ B30 تا B32 و `docs/research/world/nodes_v2_draft.json`.

- `python3 build.py` فایل `index.html` را از `template.html` و JSON می‌سازد. چیدمان دایره‌ها دستی (در `build.py`) و چیدمان نهایی نیست.
- هر دایره = یک محیط؛ هر باند = یک سرزمین (خوشهٔ مفهومی)؛ حلقهٔ آبی-بنفش با نماد کتاب = محیطی که کتاب پایهٔ انتخابی پوشش می‌دهد (جدا از رنگ سختی سبز/نارنجی/قرمز، D37)؛ دایرهٔ خط‌چین = «بیشتر بدانیم» / مسیر مخفی؛ پیکان = پیشنهاد پیش‌نیاز نرم (قفل نیست).
- پیوندهای میان سرزمین‌ها پیش‌فرض پنهان‌اند (شلوغ می‌شود)؛ با انتخاب دایره یا کلید «همهٔ پیوندها» دیده می‌شوند.
- هنوز نشان نمی‌دهد: سه چالش درون هر محیط، پوستهٔ سرزمین، رفتار نقشه روی موبایل واقعی، نقشهٔ اصلی در برابر «بیشتر بدانیم» به‌صورت لایه‌های جدا.
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود (در محیط آفلاین جایگزین سیستم).

## نسخهٔ ۲ (۲۰۲۶-۱۰-۰۷)
- ۶ سرزمین (اصطکاک در سرزمین نیرو ادغام شد).
- برچسب «آزمایشی» روی گره‌های بی‌شاهد.
- مسیر مخفی «ب»: گرهٔ مخفی با زدن «در» روی گرهٔ مبدأ پیدا می‌شود؛ قفل و امتیاز ندارد. «نمای معلم» همه را نشان می‌دهد.
- جدول قاعدهٔ عمق (باند × سبز/نارنجی/قرمز) پایین صفحه؛ مقدارها پیشنهادند.

## نسخهٔ ۵ (۸ اکتبر): ساختار B40–B43
چهار سرزمین (نیرو/حرکت/اصطکاک؛ جرم/وزن/گرانش؛ کار و انرژی؛ ماشین‌های ساده با ۳ منطقه) + سرزمین مخفی «ماشین‌های مرکب». «ماشین چیست» ورودی و «ماشین کار نمی‌سازد» پایان ماشین‌های ساده؛ در ورودی سرزمین مخفی روی E06. پیوند بین مناطق مثل پیوند بین سرزمین‌ها پیش‌فرض پنهان است.

## پایهٔ ماکت بازی (۸ اکتبر ۲۰۲۶، D62)
نسخهٔ فعلی (۴ سرزمین، ۳ منطقه، ۳۳ محیط با نام جا و سوتیتر درس، تم رنگی موقت) را مالک به‌عنوان پایهٔ ماکت بازی نگه می‌دارد؛ وقتی بازی بندر و کارت‌هایش وصل شد، دموی ناقصی از اصل بازی خواهیم داشت. برچسب گیت: `demo-base-20261008`.
