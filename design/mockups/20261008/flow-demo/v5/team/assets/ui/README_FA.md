# رابط v5 (ui-artist، گام ۲): وضعیت

همه چیز پیشنهاد/نمونه است؛ هیچ ادعای «کودک می‌فهمد» نمی‌شود. بازتولید: `python3 v5/team/ui_gen/gen_ui.py` سپس `python3 v5/team/ui_gen/shots.py`.

## فایل‌ها
- `sprite_ui.svg` (≈۱۶KB): ۲۰ آیکون `ui-ic-*` (شبکهٔ ۴۸، خط ۲٫۶)، `ui-badge-easy|mid|hard` (۵۶×۳۰، ۱/۲/۳ قله)، `ui-lock` (۳۲)، `ui-ring` (حلقهٔ اینجایی)، `ui-check` (تیک چیپ)، `ui-gearbtn` (پایهٔ دکمهٔ آیکونی ۱۲ دندانه). شناسه‌ها پیشوند `ui`.
- `assets.json`، `ui_tokens.css` (دکمه، چیپ، برگه، پلاک، کاشی، تایپوگرافی؛ بعد از light/tokens.css بیاید)، `ui_kit.html` + `shots/` (۳۹۰ و ۳۶۰، رنگی و خاکستری).
- ۲۰ آیکون: menu next close map cards practice guide search lock eye box mypos pin flag game flip lesson hint hold skip. «برگرد» = `next` با کلاس `ui-flip`.

## قرارداد
- قرص سختی: خط روز `#0d0426`؛ حاشیهٔ کرم فقط با `--ui-rim:2px` (والد `data-world=night`). واژهٔ سختی کنار قرص از کلید `difficulty.*` است (داخل قرص نیست).
- حلقه: باند زرد ۸؛ خط بیرونی با `--ui-ring-ol` (۴٫۵px؛ مزرعه ۱۰px) به بیرون ضخیم می‌شود.
- چیپ پایه: `aria-pressed=true` کرم+تیک؛ متن `<bdi dir=rtl>` «۱ تا ۲». عرض ۷۶ تا ۹۶ (در ۳۶۰ فشرده می‌شود، ارتفاع ۴۸).
- دکمه: گوشهٔ بزرگ بالا-ابتدا با ویژگی‌های منطقی؛ لبه ۶←۲ بدون جابه‌جایی؛ آیکونی با تغییر رنگ (لبه ثابت).
- متن‌ها: `difficulty.*`، `v5.ui.base.*`، `v5.ui.kit.*`، `v5.ui.state.*` در `v5/strings.fa.json` (draft)؛ بقیه از `flow.*`.
