# ماکت جریان کامل (گام ۲، نسخهٔ ۲)

ماکت قابل‌کلیک، فقط برای دیدن و نظر دادن. با کودک و گوشی واقعی آزموده نشده.

ساخت: `python3 build.py` (از `template.html`، `strings.fa.json`، `review.fa.json`، دادهٔ طرح نقشه و کارت‌های تأییدشدهٔ `design/cards/approved/`، فایل `index.html` را می‌سازد).

جریان: نقشهٔ یک‌تکه (خط مسیر) ← محیط (سه کارت مالک) ← صحنه ← کارت درس (رو/پشت) ← کارت‌دان ← آموزش ← منو ← قفل والد.

موقت: ایموجی به‌جای آیکون، صحنهٔ نارنجی/قرمز، محیط‌های غیر از اسکله (کارت ساده‌شده)، نمونهٔ «رفته‌ای». متن‌ها `draft` هستند. پرسش‌های مالک در `review.fa.json` (کلید `ask`).
