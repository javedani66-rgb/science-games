# ماکت جریان کامل (گام ۲)

ماکت قابل‌کلیک، فقط برای دیدن و نظر دادن. با کودک و گوشی واقعی آزموده نشده.

ساخت: `python3 build.py` (از `template.html`، `strings.fa.json`، `review.fa.json` و دادهٔ طرح نقشه، فایل `index.html` را می‌سازد).

جریان: نقشه ← سرزمین/منطقه ← محیط (۳ کارت چالش) ← صحنه ← کارت درس ← جعبهٔ کارت ← آموزش ← منو ← قفل والد.

موقت: ایموجی به‌جای آیکون، تصویر صحنه‌های نارنجی/قرمز، داستان‌های آن‌ها، نمونهٔ «دیده‌شده‌ها». متن‌ها `draft` هستند.
پرسش‌های مالک در `review.fa.json` (کلید `ask`) آمده است.
