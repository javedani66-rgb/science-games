# نقشهٔ پوشهٔ docs

تاریخ: ۷ اکتبر ۲۰۲۶. ورودی پروژه `START_HERE_FA.md` است؛ این فایل فقط می‌گوید هر سند کجاست.

## هستهٔ زنده (بالای docs/): همین‌ها را هر جلسه بخوان
| فایل | چیست |
|---|---|
| `STATE.md` | کجا هستیم؛ گره‌های باز |
| `DECISIONS.md` | تصمیم‌ها (D01…) |
| `PRINCIPLES.md` | دفتر اصول (A، B، C، D، E، T…) |
| `GAME_STRUCTURE_FA.md` | ساختار بازی و ارتباط بخش‌ها |
| `PROJECT_OVERVIEW_FA.md` | معرفی مشترک پروژه (از زبان مالک) |
| `FUTURE_TASKS_FA.md` | کارهای آینده |
| `MODULARITY.md`، `voice.md` | قاعدهٔ ماژولار؛ لحن استاد |
| `ARCHIVE_MANIFEST.md` | فایل‌های بیرون از گیت (Drive) |

## زیرپوشه‌ها
| پوشه | چه چیزی |
|---|---|
| `research/` | منابع و پژوهش: ثبت رفرنس‌ها (R)، ممیزی بازی ساخته‌شده و ممیزی ساختار جدید، خواندن کامل شش کتاب علوم، سطح زبان کتاب‌های فارسی، بازبینی دامنه، برنامهٔ درسی، یادآوری و مخزن، شواهد رابط کودک، پژوهش نقشه و کارت |
| `harbor/` | همهٔ مربوط به پایلوت بندر: قواعد کارت، بازبینی مالک، محتوا، پیاده‌سازی، چک‌لیست تکمیل، رنگ و هنر کارت |
| `plans/` | برنامهٔ توسعهٔ کل بازی، پایهٔ مسیر محتوا، سطوح برنامهٔ درسی |
| `handoffs/` | یادداشت تحویل هر نشست (فقط تازه‌ترین را بخوان) |
| `templates/` | قالب‌ها (گزارش توجیهی پایانی) |
| `archive/` | تاریخچه: هندآف‌ها و ممیزی‌های قدیمی؛ **برای شروع نخوان**، فقط اگر لازم شد |

## قاعده
سند تازه در پوشهٔ مناسب می‌رود و اینجا یک ردیف می‌گیرد. اصل تازه فقط در `PRINCIPLES.md`؛ تصمیم در `DECISIONS.md`؛ منبع بیرونی در `research/DESIGN_EVIDENCE_REFERENCES_FA.md`. چیزی که منسوخ شد حذف نمی‌شود، به `archive/` می‌رود.
