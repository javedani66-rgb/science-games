## ۳. چه چیزی باز است (به ترتیب)

1. **تأیید مالک برای ادغام** شاخهٔ ساخت اسکله در `main` (بخش ۱).
2. **باقی‌ماندهٔ دور ۲ اسکله:** پشت کارت درس پس از نارنجی و قرمز؛ `jt.py 8` و `mapchk.py 8` (پایهٔ اول)؛ بازبینی بصری `gal.py` برای قرقرهٔ قدیمی؛ بازبینی ۳۲۰px و ۸۴۴×۳۹۰؛ تصویر کارت قرمز اسکله (آیکون موقت `dragon-dock`)؛ شکل ملوان و دزد موقت است.
3. **`primarycompat.js` شکست می‌خورد** چون انتظار ۸ پایه دارد و اکنون ۹ است (`XFAIL` علامت خورده؛ یک خط اصلاح).
4. **آزمون کامل `--full`** یک بار روی شاخهٔ ادغام‌شده، پیش از هر انتشار. هرگز اجرا نشده.
5. **بازبینی فارسی بیرونی:** همهٔ متن‌ها `draft`اند. جریان بانک متن: `docs/texts/README_FA.md` (`export` ← مالک به GPT/Gemini ← `import` ← `--apply`).
6. **تصویر نانوبنانا** از مالک برای شش محیط ورزشگاه، بعد پایگاه فضایی، مزرعه، شهر، دریا.
7. **آزمون با کودک و گوشی واقعی:** هیچ‌کدام انجام نشده.
8. **مسیر مخفی، رنگ نشانی کتاب، نام‌گذاری نهایی** و بقیهٔ موارد باز: `docs/STATE.md` (گره‌های باز).
