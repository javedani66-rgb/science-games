# دفتر اصول پروژه — science-games

> به‌روزشده ۷ اکتبر ۲۰۲۶ پس از خواندن بسته‌های ۴ و ۶ اکتبر.

تاریخ: ۷ اکتبر ۲۰۲۶. این دفتر اصولِ پراکندهٔ اسناد پروژه را در یک جا جمع می‌کند. هیچ اصلی را خودم نساخته‌ام؛ هر ردیف منبع دارد (B13 تا B15 را مالک ۷ اکتبر در گفتگو گفت). سندی که اصول را رسمی می‌کند همچنان `docs/PROJECT_OVERVIEW_FA.md` (از زبان صاحب پروژه) است. اگر دو منبع تعارض داشتند، تصمیم متأخرتر مقدم است.

**ستون‌ها:** وضعیت = مصوب (تصمیم صاحب پروژه)، پیشنهاد (در اسناد هست ولی تأیید نشده)، منسوخ. اجرا = آیا آزمون یا ابزاری آن را خودکار می‌سنجد: بله، ناقص، خیر.

**منابع:** OV = `PROJECT_OVERVIEW_FA` (۷ اکتبر)، H4 = هندآف ۴ اکتبر (Drive)، AU = `AUDIT_2026-10-01`، CL = `CLAUDE.md`، MO = `MODULARITY.md`، VO = `voice.md`، UX = `CHILD_GAME_UX_EVIDENCE…`، CR = `HARBOR_CARD_DESIGN_RULES`، R1 تا R25 = `DESIGN_EVIDENCE_REFERENCES_FA` (مرجع، سطح راستی‌آزمایی و محدودیت هر منبع).
