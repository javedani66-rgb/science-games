# بازی‌های علوم

برای شناخت هدف پروژه و شروع کار، [از اینجا شروع کن](START_HERE_FA.md) و [معرفی مشترک پروژه](docs/PROJECT_OVERVIEW_FA.md) را بخوانید. برای ادامهٔ اجرایی، تاریخ و دامنهٔ آخرین هندآف مؤلفه را بررسی کنید.

نشانی سایت: https://javedani66-rgb.github.io/science-games/

## برای معلم
- هر بازی یک پوشه دارد؛ الان «ماشین‌های ساده» در `physics/simple-machines/`.
- پیشرفت بچه‌ها روی همان گوشی یا رایانه ذخیره می‌شود. پیام «فرستادن برای معلم» در کوله‌پشتی هم گزارش است و هم نسخهٔ پشتیبان.
- صفحهٔ معلم: `…/physics/simple-machines/#teacher` — پیام‌های بچه‌ها را یکجا بچسبانید تا جدول کلاس ساخته شود.
- برای تغییر بازی کافی است به Claude بگویید چه می‌خواهید؛ اگر گفتگوی تازه است، اسم همین مخزن (`science-games`) را هم بگویید.
